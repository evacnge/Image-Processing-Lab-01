# Image-Processing-Lab-01
This lab introduces the basic concepts of Python programming for image processing. It covers NumPy arrays and indexing, including creating arrays, matrices, zeros, ones, random values, and selecting specific rows and columns. The lab also introduces image loading and visualization using libraries such as OpenCV, PIL, and Matplotlib. Overall, the lab provides practical experience with basic Python and image-processing operations.
